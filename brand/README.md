# Piccab logo files

The mark is a picture frame (a photo with a sun and mountains) and a speech bubble with a sound wave: *see a picture, hear and say the word*. It is concept #16 from the logo sheet, redrawn in Piccab's colours. `concept-16-original.png` is the original for reference only; don't use it.

These files are not served by the site. The app's own copies are in `public/`: `favicon.svg`, `favicon.ico`, `icon-192.png`, `icon-512.png`, `icon-maskable-*.png`, `apple-touch-icon.png` and `og-image.png`.

## Which file to use

| Use | File |
|---|---|
| Logo with name, light background (slides, documents, letters) | `piccab-logo.svg` / `.png` |
| Logo with name, dark background | `piccab-logo-on-dark.svg` / `.png` |
| Mark only, light background | `piccab-mark.svg`, `piccab-mark-1024.png` |
| Mark only, dark background | `piccab-mark-on-dark.svg` |
| One colour (stamps, embroidery, print) | `piccab-mark-ink.svg`, `piccab-mark-white.svg` (the white one is for dark backgrounds) |
| Very small (under 48 px): thicker lines, 3 sound bars | `piccab-mark-small.svg`, `piccab-favicon.svg` |
| App icon (rounded tile) | `piccab-app-icon.svg` |
| App stores (square; the store rounds the corners) | `piccab-app-icon-square.svg`, `piccab-app-icon-1024.png` |
| Link previews and social posts (1200 × 630) | `piccab-social-1200x630.svg` / `.png` |

Prefer the SVGs: they stay sharp at any size and can be opened in Figma, Illustrator or Inkscape. The name is drawn as outlines (Fredoka SemiBold), so it doesn't need the font installed.

## Colours

| | Hex |
|---|---|
| Ink (frame, "Pic") | `#2d2a5a` |
| Pink (speech bubble, "cab") | `#fe5e7a`; `#e8607a` for the "cab" text on light backgrounds |
| Sun | `#ffc928` |
| Mountains | `#5b4fc4` / `#8f84e8` on light, `#b9b0f0` / `#8f84e8` on dark |
| Cream background | `#fdf9f3` |

## Keep it recognisable

- Leave clear space around the mark of at least the width of the speech bubble's tail.
- Don't stretch it, rotate it, add shadows or recolour parts of it. For a single colour, use the ink or the white version.
- Below 48 px, use the small version: the double frame and 5 sound bars blur at that size.
